# Income & Expenses (Sahil Khata)

A modern, high-performance financial management and ledger application built with Flutter and SQLite. Designed with stunning neon UI elements, real-time calculations, and seamless multi-account tracking.

## Features
- **Net Worth Tracking:** Dynamic calculation of total assets, liabilities, and balances.
- **Account & Ledger Management:** Track Bank accounts, Cash, Payables, and Receivables.
- **WhatsApp Integration:** Instantly send balance reminders and reports via WhatsApp.
- **Neon UI Design:** High-contrast dark mode with glowing gradients and custom styling.
- **Local Database:** Secure and fast local data persistence using SQLite.

## Built With
- **Framework:** Flutter (Dart)
- **Database:** sqflite
- **CI/CD:** Codemagic
